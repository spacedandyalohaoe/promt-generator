# AI Prompt Studio (for Friends & Team) 🎨⚡

Автономный веб-сервис для мгновенной генерации профессиональных промтов для **Seedream 5.0 Pro** и **GPT Image 2.5** по строгим базам знаний на базе бесплатного облака **NVIDIA NIM**.

---

## 🚀 Быстрый запуск

Сервер написан на чистом Node.js (без сторонних зависимостей npm). Запускается за 1 секунду:

```bash
cd _promt-gen
node server.js
```

Откройте в браузере: **http://localhost:3000**

---

## 🔑 Где взять бесплатный ключ NVIDIA API?

1. Зайдите на [build.nvidia.com](https://build.nvidia.com).
2. Залогиньтесь (Google / Email).
3. При регистрации NVIDIA бесплатно начисляет **1000 кредитов** для тестов моделей.
4. Откройте любую модель (например, Llama 3.3 70B) и нажмите **"Get API Key"**.
5. Скопируйте ключ вида `nvapi-...` и вставьте его прямо в поле ввода в шапке сайта (он сохранится в браузере) или в файл `.env`.

> 💡 *Без ключа сервис работает в **Демо-режиме** со встроенным шаблонизатором для предварительного просмотра.*

## 🤖 Модели NVIDIA NIM в интерфейсе

1. 🥇 **`meta/llama-3.3-70b-instruct`** *(Рекомендуется)* — лучший баланс высокой скорости и безупречного соблюдения правил оптики и запретов.
2. 🚀 **`deepseek-ai/deepseek-r1`** — мощнейший reasoning для сложных пространственных сцен и композиций.
3. 🧠 **`meta/llama-3.1-405b-instruct`** — суперфлагман на 405 млрд параметров для максимального богатства художественного языка.
4. ⚡ **`mistralai/mistral-large-2-instruct`** — идеальное следование системным инструкциям и отрицательным ограничениям.
5. 🌐 **`qwen/qwen2.5-72b-instruct`** — топовое понимание восточных языков, сложных технических схем и графики.
